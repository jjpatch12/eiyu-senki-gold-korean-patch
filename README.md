# Eiyu Senki Gold 한국어 패치 v0.9.0

현재까지 적용한 한국어화와 UI 수정 내용을 묶은 v0.9.0 일반 릴리스입니다.
정상 구매한 원본 게임이 필요하며, 게임 전체·세이브·개인 이름 데이터는 포함하지 않습니다.

## 설치

1. 릴리스에서 `EiyuSenkiGold-Korean-v0.9.0.bat` 파일 하나만 내려받습니다.
2. 게임을 종료하고 BAT을 실행해 `1. 한글패치 설치`를 선택합니다.
3. `EiyuSenkiGold.exe`가 들어 있는 게임 폴더를 선택합니다.
4. 설치 완료 메시지가 나오면 게임을 실행합니다. 글꼴이 갱신되지 않으면 Windows에 다시 로그인하세요.

Windows PowerShell 5.1과 .NET이 포함된 Windows 환경용입니다. 별도 Python, 관리자 권한, 인터넷 연결은 필요하지 않습니다.
게임 폴더 및 사용자 글꼴 폴더에 쓰기 권한이 있어야 합니다.
패치 데이터와 글꼴, 설치기, 문서는 BAT 내부에 포함되어 있습니다. 별도 ZIP이나 데이터 폴더를 받을 필요가 없습니다.
실행 중에만 숨김 임시 폴더에 풀고 종료 시 정리합니다. 임시 숨김 처리는 암호화나 접근 제한이 아닙니다.
BAT 메뉴에는 `1. 한글패치 설치`, `2. 원본 복원`만 표시됩니다.

## 패치 범위

- 본편 대사 초벌번역 및 일부 문장 검수 반영
- 화자명, 인물·도시·국가 이름과 시스템 표시 문구
- 기술명·기술 설명·아이템·임무 등 텍스트 정의의 한국어화
- 한국어 글꼴, 대사 기본 크기 30, 한글 이름 입력·표시 보완
- 주요 메뉴, 설정, 난이도, 임무 준비, 부대 관리, 전투·결과 UI 이미지
- 메뉴 선택 상태의 투명화, 정렬, 검은 잔여 테두리 수정
- 모두 보충·뒤로 버튼 및 아군 턴·적군 턴의 승인된 최신 시안
- 시작 시 오류를 유발하던 내부 음성 그룹 식별자 복원

## 알려진 제한

- 완역·전 구간 검증 완료판이 아닙니다. 보류된 미번역 행과 일부 미번역 또는 오역이 남을 수 있습니다.
- 대사 크기 30으로 확대된 상태입니다. 전 대사의 줄바꿈·오버플로 재조정은 아직 완료하지 않았습니다.
- 최신 턴 배너는 파일 검증을 마쳤지만, 모든 화면·해상도의 실기 검증을 완료하지 않았습니다.
- 이 패치의 기준 원본과 SHA-256이 일치하는 파일만 수정합니다. 다른 판본이나 임의 수정 파일은 오류를 내고 중단합니다.
- 같은 v0.9.0 파일은 건너뜁니다. 중간 작업판은 기준 원본 또는 완성본 해시와 일치하지 않으면 지원하지 않습니다.
- 한글 이름을 사용한 세이브는 게임의 `KoreanNameMap.dat`와 함께 보관하세요. 설치·복구 시 이 파일은 수정하지 않습니다.

## 백업·복구

설치 전 게임 폴더의 `_korean_patch_backup/v0.9.0_날짜시간`에 변경 대상 파일을 백업합니다.
실패하면 이번 설치에서 변경한 파일과 글꼴 등록을 되돌립니다.
같은 BAT에서 `2. 원본 복원`을 선택하고 같은 게임 폴더를 선택하면 가장 최근 v0.9.0 설치 직전 상태로 돌아갑니다.
설치 후 다른 패치로 변경된 파일이 있으면 자동 복구를 거부합니다. 백업 폴더는 삭제하지 마세요.
복구로 새로 추가된 패치 DLL·버전별 글꼴 파일이 제거될 수 있으며, 세이브는 유지됩니다.

## 배포 구성

원본 게임 파일 전체 대신 차이 데이터와 한국어 글꼴, 한글 입력 보조 DLL, 설치 스크립트만 제공합니다.
원본·결과·패치 데이터의 SHA-256을 검증하며, 설치 직전에 모든 변경 파일을 먼저 재구성합니다.
폰트는 Noto 계열을 바탕으로 게임용 이름과 문자 매핑을 수정한 파생 글꼴입니다. `OFL.txt`를 함께 배포합니다.
게임 및 원본 그래픽의 권리는 각 권리자에게 있습니다. 비공식 한국어 패치입니다.
